# airtoolkit-site

The website for [AirToolkit](https://github.com/Ayoub-EDAHLOULI/AirToolkit), an offline-first developer toolbox for air-gapped and locked-down Windows machines.

Localized into English (default), French, Spanish, German, Arabic (RTL), and Chinese, with automatic browser-language detection via `src/proxy.ts`.

## Scripts

```bash
npm install
npm run dev        # local development server
npm run lint       # ESLint
npm run build      # production build (typechecks as part of the build)
npm start          # run the production build locally
```
